# @webframp/snyk/projects

Snyk Projects — project listing, attributes, relationships, and target
management

Auto-generated by `scripts/snyk-codegen` from the Snyk REST API OpenAPI
specification.

## Credentials

Store the Snyk API token in a swamp vault and reference it with a `vault.get`
expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

## Usage

```bash
swamp extension pull @webframp/snyk/projects

swamp vault create local_encryption snyk   # once, if you have no vault yet
swamp vault put snyk API_TOKEN             # prompts; the value never touches shell history
swamp model create @webframp/snyk/projects snyk-projects \
  --global-arg 'apiToken=${{ vault.get("snyk", "API_TOKEN") }}' \
  --global-arg orgId=YOUR_ORG_ID
```

## Methods

| Method                | Description                                         |
| --------------------- | --------------------------------------------------- |
| `list_org_projects`   | List all Projects for an Org with the given Org ID. |
| `delete_org_projects` | Delete several projects in one request.             |
| `get_org_project`     | Get project by project ID.                          |
| `update_org_project`  | Updates project by project ID.                      |
| `delete_org_project`  | Delete project by project ID.                       |
| `get_sbom`            | Get a project’s SBOM document                       |
