## Summary

**High-priority GDP candidates:**
1. **Shell args (github, container-image, hermes)** — Validated once (regex), passed to Deno.Command without type-level protection. Brand as `ValidatedRepoSlug`, `ValidatedRegistry`, `ValidatedCliCommand`.
2. **Pagination limit*N** — Cap enforced at each callsite; no invariant that limit ≤ MAX_PAGES. Brand as `BoundedLimit(max)`.
3. **Nonce/lock lifecycle** — Verified after DB op but no type encoding the "verified" state.
4. **Path parameters** — Encoded at codegen time but no branded `EncodedPathParam` type.
5. **Instance names** — Sanitized before writeResource but consumers assume safety; brand as `SafeInstanceName`.
6. **Cost currency** — Raw JSON with no USD branding.
7. **Region &amp; account ID enums** — Duplicated across AWS extensions; centralize as branded types.

**Recommended starting points:**
- Create `ValidatedShellArg` and `ValidatedRepositorySlug` for github, container-image
- Create `BoundedPaginationLimit` for teams, reddit, griptape
- Unify AWS region/account validators into shared branded types in `@webframp/aws/*` base
- Add `EncodedPathSegment` to falai-codegen, griptape-codegen generated code</result>
