# @webframp/dnsimple/zones

DNSimple Zones — zones, records, batch changes, zone file, distribution checks,
NS records, activation, and DNS analytics

Auto-generated by `scripts/dnsimple-codegen` from DNSimple's API v2 OpenAPI
specification.

## Usage

```bash
swamp extension pull @webframp/dnsimple/zones
```

## Credentials

Store the DNSimple access token in a swamp vault and reference it with a
`vault.get` expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption dnsimple   # once, if you have no vault yet
swamp vault put dnsimple ACCESS_TOKEN             # prompts; the value never reaches shell history
swamp model create @webframp/dnsimple/zones dnsimple-zones \
  --global-arg 'apiToken=${{ vault.get("dnsimple", "ACCESS_TOKEN") }}' \
  --global-arg accountId=<account id from whoami>
```

If `apiToken` is unset, the model reads the `DNSIMPLE_TOKEN` environment
variable as a fallback. That value is not redacted from swamp output and is not
recommended.

## Account and environment

Account-scoped methods substitute the `accountId` global argument for the
`/{account}` path segment. It stays optional so `whoami` and `list_accounts` (in
`@webframp/dnsimple/account`) can run before you know the ID; an account-scoped
method without it fails before any request goes out.

`environment` is `production` by default. Set `--global-arg environment=sandbox`
to use DNSimple's sandbox, which has its own accounts and tokens.

## Plan limits

DNSimple's spec says a zone's records beyond the plan's `records_limit` are
either charged or cannot be created. Whether `create_zone_record` and
`batch_change_zone_records` cost anything therefore depends on your plan, so
they are not marked Billable. Check the account's limit before creating records
in bulk.

## Methods

| Method                           | Description                                           |
| -------------------------------- | ----------------------------------------------------- |
| `list_zones`                     | List zones                                            |
| `get_zone`                       | Retrieve a zone                                       |
| `get_zone_file`                  | Download a zone file                                  |
| `check_zone_distribution`        | Check zone distribution                               |
| `update_zone_ns_records`         | Update a zone's NS records                            |
| `list_zone_records`              | List zone records                                     |
| `create_zone_record`             | Create a zone record                                  |
| `get_zone_record`                | Retrieve a zone record                                |
| `update_zone_record`             | Update a zone record                                  |
| `delete_zone_record`             | Delete a zone record                                  |
| `batch_change_zone_records`      | Batch create, update, and/or delete records in a zone |
| `check_zone_record_distribution` | Check zone record distribution                        |
| `activate_zone_service`          | Activate a zone DNS service                           |
| `deactivate_zone_service`        | Deactivate a zone DNS service                         |
| `query_dns_analytics`            | Analytics about DNS queries                           |
