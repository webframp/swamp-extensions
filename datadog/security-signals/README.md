# @webframp/datadog/security-signals

Datadog Security Signals — signal search, triage, and archiving

Auto-generated by `scripts/datadog-codegen` from the Datadog v2 REST API OpenAPI
specification.

## Credentials

Datadog authenticates with two keys: an API key and an application key. Store
both in a swamp vault and reference them with `vault.get` expressions; never
pass the literal values. Any vault type works — `local_encryption`, or an
extension such as `@webframp/pass`, `@webframp/gopass`,
`@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption datadog   # once, if you have no vault yet
swamp vault put datadog API_KEY               # prompts; the value never touches shell history
swamp vault put datadog APP_KEY
```

## Usage

```bash
swamp extension pull @webframp/datadog/security-signals

swamp model create @webframp/datadog/security-signals dd-security-signals \
  --global-arg 'apiKey=${{ vault.get("datadog", "API_KEY") }}' \
  --global-arg 'appKey=${{ vault.get("datadog", "APP_KEY") }}' \
  --global-arg site=us1
```

## Methods

| Method                                           | Description                                       |
| ------------------------------------------------ | ------------------------------------------------- |
| `list_security_monitoring_signals`               | Get a quick list of security signals              |
| `bulk_edit_security_monitoring_signals_assignee` | Bulk update triage assignee of security signals   |
| `bulk_edit_security_monitoring_signals_state`    | Bulk update triage state of security signals      |
| `bulk_edit_security_monitoring_signals`          | Bulk update security signals                      |
| `search_security_monitoring_signals`             | Get a list of security signals                    |
| `get_security_monitoring_signal`                 | Get a signal's details                            |
| `edit_security_monitoring_signal_assignee`       | Modify the triage assignee of a security signal   |
| `edit_security_monitoring_signal_incidents`      | Change the related incidents of a security signal |
| `get_investigation_log_queries_matching_signal`  | Get investigation queries for a signal            |
| `edit_security_monitoring_signal_state`          | Change the triage state of a security signal      |
| `get_suggested_actions_matching_signal`          | Get suggested actions for a signal                |
| `edit_security_monitoring_signal`                | Update security signal triage state or assignee   |
