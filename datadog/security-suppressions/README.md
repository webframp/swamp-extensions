# @webframp/datadog/security-suppressions

Datadog Security Suppressions — suppression rule management

Auto-generated by `scripts/datadog-codegen` from the Datadog v2 REST API OpenAPI
specification.

## Credentials

Datadog authenticates with two keys: an API key and an application key. Store
both in a swamp vault and reference them with `vault.get` expressions; never
pass the literal values. Any vault type works — `local_encryption`, or an
extension such as `@webframp/pass`, `@webframp/gopass`,
`@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption datadog   # once, if you have no vault yet
swamp vault put datadog API_KEY               # prompts; the value never touches shell history
swamp vault put datadog APP_KEY
```

## Usage

```bash
swamp extension pull @webframp/datadog/security-suppressions

swamp model create @webframp/datadog/security-suppressions dd-security-suppressions \
  --global-arg 'apiKey=${{ vault.get("datadog", "API_KEY") }}' \
  --global-arg 'appKey=${{ vault.get("datadog", "APP_KEY") }}' \
  --global-arg site=us1
```

| `get_suppressions_affecting_future_rule`   | Get suppressions affecting future rule     |
| `get_suppressions_affecting_rule`          | Get suppressions affecting a specific rule |
| `validate_security_monitoring_suppression` | Validate a suppression rule                |
