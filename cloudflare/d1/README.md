# @webframp/cloudflare/d1

Cloudflare D1 serverless SQL databases — databases, queries

Auto-generated by `scripts/cloudflare-codegen` from the Cloudflare OpenAPI
specification.

## Credentials

Store the API token in a swamp vault and reference it with a `vault.get`
expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption cloudflare   # once, if you have no vault yet
swamp vault put cloudflare API_TOKEN             # prompts; the value never touches shell history
```

When `apiToken` is unset, the model falls back to the `CLOUDFLARE_API_TOKEN`
environment variable. Swamp does not redact that variable, so it is not
recommended.

## Usage

```bash
swamp extension pull @webframp/cloudflare/d1

swamp model create @webframp/cloudflare/d1 cf-d1 \
  --global-arg 'apiToken=${{ vault.get("cloudflare", "API_TOKEN") }}' \
  --global-arg accountId=YOUR_ACCOUNT_ID
```

## Methods

| --------------------------- | -------------------------------------------------- |
| `list_databases`            | List D1 Databases                                  |
| `create_database`           | Create D1 Database                                 |
| `get_database`              | Get D1 Database                                    |
| `update_database`           | Update D1 Database                                 |
| `update_partial_database`   | Update D1 Database partially                       |
| `delete_database`           | Delete D1 Database                                 |
| `create_d1_export_database` | Export D1 Database as SQL                          |
| `d1_import_database`        | Import SQL into your D1 Database                   |
| `d1_query_database`         | Query D1 Database                                  |
| `d1_raw_database_query`     | Raw D1 Database query                              |
| `get_bookmark`              | Get D1 database bookmark                           |
| `d1_time_travel_restore`    | Restore D1 Database to a bookmark or point in time |
