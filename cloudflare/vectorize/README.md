# @webframp/cloudflare/vectorize

Cloudflare Vectorize — vector indexes, insert/query/delete operations

Auto-generated by `scripts/cloudflare-codegen` from the Cloudflare OpenAPI
specification.

## Credentials

Store the API token in a swamp vault and reference it with a `vault.get`
expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption cloudflare   # once, if you have no vault yet
swamp vault put cloudflare API_TOKEN             # prompts; the value never touches shell history
```

When `apiToken` is unset, the model falls back to the `CLOUDFLARE_API_TOKEN`
environment variable. Swamp does not redact that variable, so it is not
recommended.

## Usage

```bash
swamp extension pull @webframp/cloudflare/vectorize

swamp model create @webframp/cloudflare/vectorize cf-vectorize \
  --global-arg 'apiToken=${{ vault.get("cloudflare", "API_TOKEN") }}' \
  --global-arg accountId=YOUR_ACCOUNT_ID
```
