# @webframp/cloudflare/tunnel

Cloudflare Tunnel — tunnel management, configurations, connections

Auto-generated by `scripts/cloudflare-codegen` from the Cloudflare OpenAPI
specification.

## Credentials

Store the API token in a swamp vault and reference it with a `vault.get`
expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption cloudflare   # once, if you have no vault yet
swamp vault put cloudflare API_TOKEN             # prompts; the value never touches shell history
```

Some methods return secrets, which swamp stores in a vault (see
[Secrets](#secrets)). Because the model declares such fields, swamp refuses to
run any of its methods, reads included, until a vault exists
(`swamp vault create local_encryption cloudflare`).

When `apiToken` is unset, the model falls back to the `CLOUDFLARE_API_TOKEN`
environment variable. Swamp does not redact that variable, so it is not
recommended.

## Usage

```bash
swamp extension pull @webframp/cloudflare/tunnel

swamp model create @webframp/cloudflare/tunnel cf-tunnel \
  --global-arg 'apiToken=${{ vault.get("cloudflare", "API_TOKEN") }}' \
  --global-arg accountId=YOUR_ACCOUNT_ID
```

## Secrets

Pass every secret input as a `${{ vault.get("<vault>", "<KEY>") }}` expression,
never as a literal value. Swamp then redacts it from logs and run records.

When a method returns a secret, swamp stores it in a vault and the resource
keeps only a vault reference. Because the model declares such fields, swamp
refuses to run any of its methods, reads included, until a vault exists
(`swamp vault create local_encryption cloudflare`).

| Method                                     | Secret inputs   | Stored in a vault | Removed before storing |
| ------------------------------------------ | --------------- | ----------------- | ---------------------- |
| `create_a_cloudflare_tunnel`               | `tunnel_secret` | —                 | —                      |
| `update_a_cloudflare_tunnel`               | `tunnel_secret` | —                 | —                      |
| `get_a_cloudflare_tunnel_management_token` | —               | `value`           | —                      |
| `get_a_cloudflare_tunnel_token`            | —               | `value`           | —                      |
