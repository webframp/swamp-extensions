# @webframp/cloudflare/spectrum

Cloudflare Spectrum — TCP/UDP proxying for non-HTTP applications

Auto-generated by `scripts/cloudflare-codegen` from the Cloudflare OpenAPI
specification.

## Credentials

Store the API token in a swamp vault and reference it with a `vault.get`
expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption cloudflare   # once, if you have no vault yet
swamp vault put cloudflare API_TOKEN             # prompts; the value never touches shell history
```

When `apiToken` is unset, the model falls back to the `CLOUDFLARE_API_TOKEN`
environment variable. Swamp does not redact that variable, so it is not
recommended.

## Usage

```bash
swamp extension pull @webframp/cloudflare/spectrum

swamp model create @webframp/cloudflare/spectrum cf-spectrum \
  --global-arg 'apiToken=${{ vault.get("cloudflare", "API_TOKEN") }}' \
  --global-arg zoneId=YOUR_ZONE_ID
```

## Methods

| Method                                                                  | Description                                                           |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `get_current_aggregated_analytics`                                      | Get current aggregated analytics                                      |
| `get_analytics_by_time`                                                 | Get analytics by time                                                 |
| `get_analytics_summary`                                                 | Get analytics summary                                                 |
| `list_spectrum_applications`                                            | List Spectrum applications                                            |
| `create_spectrum_application_using_a_name_for_the_origin`               | Create Spectrum application using a name for the origin               |
| `get_spectrum_application_configuration`                                | Get Spectrum application configuration                                |
| `update_spectrum_application_configuration_using_a_name_for_the_origin` | Update Spectrum application configuration using a name for the origin |
| `delete_spectrum_application`                                           | Delete Spectrum application                                           |
