# @webframp/falai/organization

fal.ai Organization — teams, usage, billing events, focus reports

Auto-generated by `scripts/falai-codegen` from the fal.ai Platform APIs OpenAPI
specification.

## Usage

```bash
swamp extension pull @webframp/falai/organization

swamp model create @webframp/falai/organization falai-organization \
  --global-arg apiToken=FAL_API_KEY
```

If `apiToken` is omitted, the model falls back to the `FAL_KEY` environment
variable (fal.ai's standard SDK env var).

## Methods

| Method                            | Description                 |
| --------------------------------- | --------------------------- |
| `get_organization_billing_events` | Organization Billing Events |
| `get_organization_teams`          | Organization Teams          |
| `get_organization_usage`          | Organization Usage          |
