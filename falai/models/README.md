# @webframp/falai/models

fal.ai Models — model catalog, pricing, analytics, usage, billing events,
request search

Auto-generated by `scripts/falai-codegen` from the fal.ai Platform APIs OpenAPI
specification.

## Usage

```bash
swamp extension pull @webframp/falai/models
```

## Credentials

Store the fal.ai API key in a swamp vault and reference it with a `vault.get`
expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp vault create local_encryption falai   # once, if you have no vault yet
swamp vault put falai API_KEY               # prompts; the value never touches shell history
swamp model create @webframp/falai/models falai-models \
  --global-arg 'apiToken=${{ vault.get("falai", "API_KEY") }}'
```

If `apiToken` is unset, the model reads the `FAL_KEY` environment variable as a
fallback. That value is not redacted from swamp output and is not recommended.

## Methods

| Method                      | Description                                           |
| --------------------------- | ----------------------------------------------------- |
| `get_model_insights`        | Published model insights and weekly statistics (beta) |
| `get_models`                | Model search                                          |
| `get_pricing`               | Pricing                                               |
| `estimate_pricing`          | Estimate cost                                         |
| `get_usage`                 | Usage                                                 |
| `get_analytics`             | Analytics                                             |
| `get_billing_events`        | Billing Events                                        |
| `delete_request_payloads`   | Delete request payloads                               |
| `list_requests_by_endpoint` | List requests by endpoint(s)                          |
| `search_requests`           | Search Requests                                       |
