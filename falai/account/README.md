# @webframp/falai/account

fal.ai Account — billing, focus reports, model access controls, and account
metadata

Auto-generated by `scripts/falai-codegen` from the fal.ai Platform APIs OpenAPI
specification.

## Usage

```bash
swamp extension pull @webframp/falai/account

swamp model create @webframp/falai/account falai-account \
  --global-arg apiToken=FAL_API_KEY
```

If `apiToken` is omitted, the model falls back to the `FAL_KEY` environment
variable (fal.ai's standard SDK env var).

## Methods

| Method                | Description           |
| --------------------- | --------------------- |
| `get_account_billing` | Account Billing       |
| `get_meta`            | Get platform metadata |
