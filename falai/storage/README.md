# @webframp/falai/storage

fal.ai Storage — file ACLs, signed URLs, storage settings

Auto-generated by `scripts/falai-codegen` from the fal.ai Platform APIs OpenAPI
specification.

## Usage

```bash
swamp extension pull @webframp/falai/storage

swamp model create @webframp/falai/storage falai-storage \
  --global-arg apiToken=FAL_API_KEY
```

If `apiToken` is omitted, the model falls back to the `FAL_KEY` environment
variable (fal.ai's standard SDK env var).

## Methods

| Method                    | Description             |
| ------------------------- | ----------------------- |
| `get_storage_file_acl`    | Get file ACL            |
| `set_storage_file_acl`    | Set file ACL            |
| `sign_storage_file_url`   | Sign file URL           |
| `get_storage_settings`    | Get storage settings    |
| `update_storage_settings` | Update storage settings |
