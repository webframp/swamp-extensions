# @webframp/falai/serverless

fal.ai Serverless — app deployments, queue, revisions, files, logs, metrics,
requests, usage

Auto-generated by `scripts/falai-codegen` from the fal.ai Platform APIs OpenAPI
specification.

## Usage

```bash
swamp extension pull @webframp/falai/serverless

swamp model create @webframp/falai/serverless falai-serverless \
  --global-arg apiToken=FAL_API_KEY
```

If `apiToken` is omitted, the model falls back to the `FAL_KEY` environment
variable (fal.ai's standard SDK env var).
