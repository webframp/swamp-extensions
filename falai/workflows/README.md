# @webframp/falai/workflows

fal.ai Workflows — workflow definitions

Auto-generated by `scripts/falai-codegen` from the fal.ai Platform APIs OpenAPI
specification.

## Usage

```bash
swamp extension pull @webframp/falai/workflows

swamp model create @webframp/falai/workflows falai-workflows \
  --global-arg apiToken=FAL_API_KEY
```

If `apiToken` is omitted, the model falls back to the `FAL_KEY` environment
variable (fal.ai's standard SDK env var).

## Methods

| Method            | Description          |
| ----------------- | -------------------- |
| `list_workflows`  | List user workflows  |
| `create_workflow` | Create a workflow    |
| `get_workflow`    | Get workflow details |
