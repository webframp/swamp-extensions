# @webframp/griptape/structures

Griptape Cloud Structures — deployed structures, runs, logs, and spans

Auto-generated by `scripts/griptape-codegen` from the Griptape Cloud OpenAPI
specification.

## Credentials

Store the Griptape Cloud API key in a swamp vault and reference it with a
`vault.get` expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp extension pull @webframp/griptape/structures

swamp vault create local_encryption griptape   # once, if you have no vault yet
swamp vault put griptape API_KEY               # prompts; the value never touches shell history
swamp model create @webframp/griptape/structures gt-structures \
  --global-arg 'apiKey=${{ vault.get("griptape", "API_KEY") }}'
```

The `GT_CLOUD_API_KEY` environment variable is read as a fallback when `apiKey`
is unset, but it is not redacted and is not recommended. An optional `baseUrl`
argument overrides `GT_CLOUD_BASE_URL` and the built-in default
(`https://cloud.griptape.ai`).

## Secrets

### Secret-valued arguments

These method arguments carry a credential:

- `create_structure_deployment`: `code_source`
- `get_invoke_structure_webhook_get`: `api_key`
- `invoke_structure_webhook_post`: `api_key`

Method inputs are recorded with the run. Pass a credential as a `vault.get`
expression so the recorded input holds the reference, not the secret; a literal
value is recorded in cleartext.

```bash
swamp model method run gt-structures get_invoke_structure_webhook_get \
  --input 'api_key=${{ vault.get("griptape", "<KEY>") }}'
```

`code_source` is an object that holds the credential in one of its fields. Put
the `vault.get` expression on that field, not the literal value.
