## Credentials

Store the Griptape Cloud API key in a swamp vault and reference it with a
`vault.get` expression; never pass the literal value. Any vault type works —
`local_encryption`, or an extension such as `@webframp/pass`,
`@webframp/gopass`, `@webframp/hashicorp-vault` or `@webframp/macos-keychain`.

```bash
swamp extension pull @webframp/griptape/models

swamp vault create local_encryption griptape   # once, if you have no vault yet
swamp vault put griptape API_KEY               # prompts; the value never touches shell history
swamp model create @webframp/griptape/models gt-models \
  --global-arg 'apiKey=${{ vault.get("griptape", "API_KEY") }}'
```

The `GT_CLOUD_API_KEY` environment variable is read as a fallback when `apiKey`
is unset, but it is not redacted and is not recommended. An optional `baseUrl`
argument overrides `GT_CLOUD_BASE_URL` and the built-in default
(`https://cloud.griptape.ai`).
